# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-10-18

### Added
- `DataScienceEcosystem.ipynb`: overview of data science languages, libraries, and tools.
- `CreateandShareyourJupyterNotebook.ipynb`: statistical hypothesis testing on the Boston Housing dataset (t-test, ANOVA, Pearson correlation, OLS regression).
- `WebScarping.ipynb`: stock price extraction (`yfinance`) and revenue web scraping for Tesla and GameStop, with interactive Plotly dashboards.
- `requirements.txt`, MIT `LICENSE`, and this changelog.
- `.github/workflows/ci.yml`: GitHub Actions pipeline validating notebook integrity.

### Changed
- Rewrote `README.md` with an accurate description of all three notebooks.
